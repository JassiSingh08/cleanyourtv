# Everything is DISABLED, not uninstalled. Comment out any line you want to keep.

# Stock launcher: com.google.android.apps.tv.launcherx (about 210 MB of RAM across two processes).
# Live TV / HDMI app: com.smartdevice.livetv. Keep it, and keep com.mediatek.tvinput,
# com.mediatek.tv.service, com.smartdevice.bleconnectservice (remote pairing and battery),
# com.smartdevice.ipcontrol, com.mediatek.OledFuctionService and com.google.android.tv.assistant (mic LED).
#
# Known quirks on this firmware:
# - Do NOT disable com.google.android.apps.tv.launcherx. The setup wizard (setupwraith) has a
#   priority-1 HOME RecoveryActivity that shell can't disable, so with launcherx off Home shows a
#   black screen. Disabling setupwraith itself soft-reboots the TV. Install the launcher with
#   HOME_GUARD=1 launcher/build-and-install.sh instead: launcherx stays enabled and an accessibility
#   service redirects the Home button.
# - dreamx is disabled below; point the screensaver at the launcher's clock:
#   settings put secure screensaver_components com.gathin.tvhome/.ClockDream
# - screencap prints driver noise to stdout, so `adb exec-out screencap -p` gives a broken PNG.
#   Use tools/shot.sh, which writes on the TV and pulls.
